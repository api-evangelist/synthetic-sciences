# Atlas Docs

Atlas by Synthetic Sciences is the agent-first protocol and infrastructure for
autonomous research — the shared substrate between humans, agents, code,
sources, and public graphs. Agents read and write it directly over the CLI and
REST; graphs can be private, shared with collaborators, browsed publicly, and
forked.

## Agent-first workflow

Run `atlas init` in a research repo to write `atlas.json`. That file is the
opt-in activation contract for quiet agent behavior: load `brief` when context
matters, auto-scope `library:*`, use `web:*` for provenance-capturing web
search/fetch, and write compact breadcrumbs with `log:*`. If Atlas is not
available or not relevant, agents should fail open and continue normally.

Sharing is graph-scoped: visibility (private/unlisted/public) and roles
(viewer/editor/admin) live on the project root and descendants inherit. Public
graphs can be browsed and continued by forking — `atlas fork --node <id>` copies
a visible graph/subtree into your account, preserving code-state and provenance.
